# progra2-terceraserie
Tercera serie, primer parcial
## Ejercicio 1 - Registro de Ticket

### Objetivo
Construir un primer registro usando entrada, conversión, condicionales, listas y diccionarios.

### Enunciado
Desarrollar el archivo `01_registro_ticket.py` que permita registrar un ticket solicitando número de ticket, solicitante, título, descripción, categoría y prioridad.

El programa valida el número del ticket mediante `try/except ValueError`, rechaza campos obligatorios vacíos, valida las categorías y prioridades permitidas, guarda la información en un diccionario con estado inicial `Open` y muestra un resumen utilizando f-strings.

### Pruebas realizadas
- Número de ticket inválido.
- Campo obligatorio vacío.
- Registro válido.
